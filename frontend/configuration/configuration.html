Quotation & invoice defaults

Applied across the whole team

HSN code

A shared classification code for all SKU items.

Enter 4, 6 or 8 digits.

i

Applies to order items and new PI previews. Existing previews and issued invoices keep their saved code.

Maximum PI discount

Applies to percentage discounts, fixed amounts and invoice price reductions for all users. Until configured, the limit is 0%.

%

SKU lookup limit

Maximum SKUs in one quotation, enquiry, or stock check request.

SKUs

Choose 1 to 500. Requests above the limit are rejected before any SKU lookup.

PI number sequence

Set the last number used. Each successfully generated PI confirms the next number with its generator’s department prefix.

For example, enter 100 and the next PI will use 101. The sequence is shared across departments.

Departments

Organise your team with consistent department names.

Available departmentsUsed in user profiles

    Add a department

    Department PI prefixes

    Choose a department and set its invoice prefix. For example, PIs generated by a user in the AMT department use AMT/ followed by the next number in the shared sequence.

    Leave blank to remove the default. Saved orders and issued invoices keep their existing numbers.
